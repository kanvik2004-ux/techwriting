# How to install VS code 

Visual Studio Code (VS Code) is a popular, lightweight code editor developed by Microsoft.  
It supports multiple programming languages and provides extensions for debugging, Git integration, and more.

---

## 🖥️ Prerequisites
Before you begin, make sure you have:
- A Windows 10 or 11 computer
- Internet connection
- Administrator access to install software

---

## 📥 Step 1: Download VS Code

1. Open your browser and go to the official website:  
   👉 [https://code.visualstudio.com](https://code.visualstudio.com)
2. Click on the **Download for Windows** button.
3. The setup file (something like `VSCodeSetup-x64-x.x.x.exe`) will start downloading.

---

## ⚙️ Step 2: Run the Installer

1. Locate the downloaded file in your **Downloads** folder.
2. Double-click to start the installation.
3. Accept the license agreement and click **Next**.
4. Choose the destination folder (or keep the default path).
5. Check these boxes for convenience:
   - ✅ Add “Open with Code” to right-click menu
   - ✅ Add to PATH (important)
6. Click **Install**.

---

## 🚀 Step 3: Launch VS Code

1. After installation, click **Finish** to launch VS Code.
2. You’ll see the **Welcome Page**.
3. You can now start creating files or open existing projects.

---

## 🔌 Step 4: (Optional) Install Useful Extensions

To make VS Code more powerful:
- Open the **Extensions** panel (shortcut: `Ctrl + Shift + X`)
- Search and install:
  - *Prettier* (Code formatter)
  - *Python* (for Python coding)
  - *Markdown All in One*
  - *GitLens*
